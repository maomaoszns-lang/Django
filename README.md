#### 介绍
devops的运维平台
 1. 权限管理
 2. 服务器日志(采集agent端多台服务器日志 /var/log/messages  aget端采集成功->做告警匹配规则-匹配成功上传->通知->告警12小时未处理系统会自动处理(现场告警未处理完会在次通报))
 3. Linux管理(xshell终端操作界面)
 4. Ansible管理(提供了k8s高可用部署剧本,自己可以写ansible-playbook 剧本  修改Host)
